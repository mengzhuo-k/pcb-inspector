焊视 PCB 焊接质量检测 1.0.0（Windows 10/11 64 位）

安装包包含 Python 3.11、CPU 版推理与训练依赖、当前检测模型、训练图库、模型历史及检验记录。
安装后无需另外安装 Python，也无需联网下载依赖。

使用：双击桌面“焊视 PCB 检测”，等待模型加载后会自动打开浏览器。
关闭浏览器后后台服务继续运行，可在开始菜单选择“停止焊视后台服务”。
本机端口被占用时会自动选择其他空闲端口。

数据保存在安装目录的 data 文件夹，开始菜单提供打开入口。
升级安装不会覆盖已有数据，卸载会保留 data 中的检验记录及模型。
若需备份，请先停止后台服务，再复制整个 data 文件夹。

不包含开发虚拟环境、Git 仓库、重复 ZIP 包、原始下载数据集和临时训练任务副本。
现有模型适用范围和数据来源见安装目录 README.md 与 models/DATASET-LICENSE.md。
